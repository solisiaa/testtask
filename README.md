# Список задач

Небольшое веб-приложение на HTML, CSS и JavaScript. Откройте `index.html` в браузере. Для запуска через локальный сервер выполните `python3 -m http.server 8000` в папке проекта и откройте `http://localhost:8000`.

Введите название задачи и нажмите «Добавить». Флажок рядом с задачей переключает её статус, а кнопка «Удалить» убирает её из списка. Список и статусы хранятся в `localStorage` и восстанавливаются после обновления страницы в том же браузере.

Для написания кода и проверки сценариев использовался OpenAI Codex.
